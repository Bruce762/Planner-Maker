# 日程本工作室

一個可以離線使用的日程本編輯器。打開 `planner_studio.html`，就能選擇樣式、調整版面、填寫內容，再匯出成 PDF。

不用安裝程式、註冊帳號或架設伺服器。所有編輯與檔案產生都在你的裝置上完成。

## 本地使用開始使用

1. 將 `planner_studio.html` 下載到電腦。
2. 用瀏覽器開啟檔案。
3. 在左側「頁面」設定年份、名稱與封面文字。
4. 到「樣式」選擇設計，再用「排版」調整紙張和欄位。
5. 點選紙面上的空白區，直接輸入內容。
6. 完成後切到「預覽」，確認版面，再按右上角「匯出 PDF」。

第一次使用，可以先編輯一個月份、匯出幾頁，確認自己喜歡這個版面後，再製作整本。

如果畫面只有工具列、右側卻沒有日程本，可能是檔案預覽沒有執行互動程式。請改用瀏覽器開啟。手機或平板的檔案預覽不一定能使用完整功能。

## 先認識畫面

| 位置               | 可以做什麼                                             |
| ------------------ | ------------------------------------------------------ |
| 左側「頁面」       | 切換封面、全年日曆、月份與日期；修改基本內容和年度目標 |
| 左側「樣式」       | 選擇日程本設計，調整配色、字體、文字大小與行距         |
| 左側「排版」       | 調整紙張、邊界、頁面順序、月曆與每日頁配置             |
| 中間紙面           | 直接書寫、選取區塊，以及拖曳調整                       |
| 右側「區塊編輯」   | 更改選中區塊的名稱、底紋、大小和順序                   |
| 上方「編輯／預覽」 | 切換編輯畫面與實際 PDF 版面                            |
| 下方頁面選單       | 切換上一頁、下一頁或指定頁面                           |

畫面較窄時，左側工具會收進選單，右側則透過「區塊編輯」按鈕開啟。紙面太小，可以把縮放改為 100% 或 120%。

## 選擇日程本設計

目前有五套樣式，每套都包含封面與內頁設計。

| 樣式 | 特色                               |
| ---- | ---------------------------------- |
| 經典 | 原有版型，格線清楚，適合日常安排   |
| 刊物 | 明體字形與粗細線條，接近書刊的排版 |
| 留白 | 開放格線與較多留白，視覺較輕       |
| 秩序 | 數字標記與明確分區，結構俐落       |
| 柔光 | 柔和色塊與圓角書寫區               |

切換樣式會更新配色、字體及部分版面設定，已填寫的內容與自訂紀錄區會保留。選好樣式後，仍可繼續調整顏色和排版。

編輯器的淡灰藍底色與日程本配色分開設定，不會一起印進 PDF。

## 編輯月曆與每日紀錄

### 月曆

點選日期格子中的空白處，就能輸入當天的安排。點日期數字，則會前往對應的每日頁。

拖曳格子內的移動把手，可以把內容移到另一個日期。如果兩邊都有文字，會交換兩天的內容，不會直接覆蓋。

月曆格子與每日紀錄分開保存。移動月曆內容，不會連同每日頁的紀錄一起搬動。

在「排版」可以設定星期一或星期日開始，也能把下方的重點與備忘改成各一行、各兩行，或隱藏。

### 每日頁

點選時間欄或書寫區即可輸入。右側可以新增自訂區塊，例如閱讀筆記、運動紀錄或工作追蹤，最多保留六個紀錄區。

每個區塊可以：

- 更改名稱與標題顏色。
- 選擇橫線、點陣、空白或待辦格底紋。
- 調整高度比例、顯示或隱藏。
- 複製、移除，或用上移、下移按鈕排序。

拖曳標題旁的把手，可以改變區塊順序。雙欄版面中，拖動兩欄之間的分隔線，可以調整時間軸寬度。

**區塊與版面設定會套用到整年的每日頁；書寫內容只保存在目前日期。** 拖曳功能用來排序和調整比例，並不是把區塊任意放到紙面上的任何位置。

每日頁右上角和頁底都有淡色的「返回月曆」文字連結。

## 匯出 PDF

1. 按「預覽」確認實際輸出外觀。
2. 按右上角「匯出 PDF」。
3. 選擇輸出範圍。
4. 按「下載彩色 PDF」，等待檔案產生。

可輸出整本、全年日曆與月曆、目前月份與每日紀錄，或目前這一頁。

PDF 會保留配色與固定版面，並加入月份、日期及返回月曆的跳轉連結。連結只會指向這次輸出包含的頁面。例如只匯出一張每日頁，因為沒有附上月曆，就不會加入返回月曆的有效連結。

PDF 以影像保存頁面，文字無法直接選取或搜尋。要修改文字，請回到編輯器修改後再匯出。不同裝置使用的字體可能略有差異，以「預覽」顯示為準。

整本檔案較大，手機或平板可以先按月份輸出。產生檔案時請保持頁面開啟；需要停止時，按輸出視窗右上角的關閉按鈕。

## 儲存與備份

| 功能      | 下載的檔案 | 適合什麼時候用                                 |
| --------- | ---------- | ---------------------------------------------- |
| 備份      | JSON       | 保存設定與紀錄，之後匯入編輯器繼續使用         |
| 儲存 HTML | HTML       | 保存一份內含目前內容、可以直接開啟的完整編輯器 |
| 匯出 PDF  | PDF        | 閱讀、列印或放進筆記軟體使用                   |

瀏覽器會嘗試在本機暫存內容，但不會直接改寫你最初下載的 HTML。清除瀏覽資料、使用私人模式或移動檔案，都可能讓暫存失效。重要內容請另外下載保存。

換裝置或更新編輯器時，先在舊版按「備份」，再到新版左側「頁面」中的「匯入備份檔案」載入 JSON。匯入會取代目前的設定與紀錄。

## 改錯了怎麼辦？

上方的「復原」和「重做」可以撤回或恢復操作。紀錄保留在這次開啟的工作階段，重新開啟後不會保留。

| 快捷鍵               | 功能                                       |
| -------------------- | ------------------------------------------ |
| Ctrl／⌘ + Z         | 復原；正在輸入文字時使用文字欄位的復原功能 |
| Ctrl／⌘ + Shift + Z | 不在文字欄位中時，重做編輯操作             |
| Ctrl／⌘ + S         | 下載 JSON 備份                             |
| Alt + ↑／↓         | 上移或下移選中的每日紀錄區                 |

「還原設計設定」會把版面設定恢復預設，保留目前年份與已填寫的紀錄。自訂區塊可能不再顯示，使用前可以先下載備份。

## 常見問題

**內容被切掉了？**

文字超出格子高度時，PDF 會截去超出的部分。可以縮短文字、縮小字級，或增加區塊高度，再到「預覽」確認。

**PDF 的顏色或格式不對？**

請使用編輯器右上角的「匯出 PDF」。這個功能直接產生固定版面的彩色 PDF，不需要調整瀏覽器的列印設定。

**返回月曆沒有反應？**

先確認輸出的 PDF 有包含該月份的月曆。只輸出單頁時，不會加入指向未輸出頁面的連結。網頁中也需要啟用「每日紀錄」，才能從月曆跳到每日頁。

**換了新版，之前的內容在哪裡？**

新版不會自動合併舊檔案。請從舊版下載 JSON 備份，再匯入新版；如果先前有用「儲存 HTML」，也可以開啟那份檔案繼續編輯。
